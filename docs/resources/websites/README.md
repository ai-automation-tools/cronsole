TaskHub's **Platforms** tab is a launchpad to the scheduling screens of the tools you
already use. Some of these have public APIs TaskHub can integrate with; others are
quick-links only until an API appears.

## ⏰ Native scheduler UIs

| Platform | Status in TaskHub |
|:---|:---|
| [**Claude Routines**](https://claude.ai/code/routines) | Experimental connector via the Anthropic API. |
| [**ChatGPT Schedules**](https://chatgpt.com/schedules) | Quick link — no public automations API today. |
| [**Gemini Scheduled**](https://gemini.google.com/scheduled) | Quick link. |

You can also add your own custom links (e.g. n8n, Open Claw, Hermes) from the Platforms tab;
they're saved locally and grouped under a **User Defined** section.

## 🌍 Reference sites

| Site | Why it's useful |
|:---|:---|
| [**crontab.guru**](https://crontab.guru/) | Sanity-check cron expressions (TaskHub stores schedules as 5-field cron). |
| [**Windows Task Scheduler docs**](https://learn.microsoft.com/en-us/windows/win32/taskschd/task-scheduler-start-page) | Reference for the platform the Windows agent wraps. |
