# Cronsole Connect Pack

**v1.9** · canonical copy: <https://cronsole.mikesailab.com>

Teach any AI tool — Claude Code, Claude Desktop, Cursor, Codex, or your own agent — to create
and manage scheduled tasks through **your** running Cronsole.

Everything here describes how to **use** Cronsole. None of it requires the Cronsole source code.

## What's in the pack

| File | For |
|:---|:---|
| `SKILL.md` | Hosts that support skills (Claude Code, Claude Desktop). Drop the whole folder in and the tool loads it when the work matches. |
| `references/task-authoring.md` | The long form: every creation path, command recipes per kind of work, quoting, folders, the schedule traps, how to verify. |
| `AGENTS.md` | Hosts with **no** skill concept. One self-contained file to paste into a system prompt, `AGENTS.md`, `CLAUDE.md`, or custom instructions. |
| `mcp-config.json` | The MCP server wiring, with the traps documented inline. |

## Install

### 1. Wire up the MCP server (recommended)

Merge the `cronsole` block from `mcp-config.json` into your host's MCP config, then:

```bash
cd <path-to-cronsole>/mcp-server && npm run build
```

Export your token in the environment you launch the host from:

```powershell
# Windows — then open a FRESH terminal, environments are inherited at process start
[Environment]::SetEnvironmentVariable('CRONSOLE_TOKEN', '<jwt>', 'User')
```

```bash
# POSIX
export CRONSOLE_TOKEN='<jwt>'
```

Verify: ask your tool to list your scheduled tasks. If the `cronsole` tools are **missing**
rather than erroring, the token was unset — the server refuses to start rather than send a
literal `${CRONSOLE_TOKEN}` and get back a misleading `403 Invalid or expired token`.

**No MCP support in your tool?** Skip this step. The REST API at `http://localhost:3000/api`
does everything, with `Authorization: Bearer <token>`.

### 2. Install the instructions

**Claude Code / Claude Desktop** — copy the skill into your skills directory:

```
.claude/skills/cronsole/SKILL.md
.claude/skills/cronsole/references/task-authoring.md
```

(Or `~/.claude/skills/cronsole/` to make it available everywhere.)

**Cursor, Codex, Windsurf, custom agents** — paste `AGENTS.md` into the tool's instruction
file or system prompt. Keep `references/task-authoring.md` nearby for when you need detail.

**Your own agent** — `AGENTS.md` is written to work as a system prompt as-is.

## Before you let a tool loose on this

Cronsole creates **real** scheduled tasks that run unattended and, on Windows, elevated. The
pack front-loads the rules that matter — schedules are UTC cron, an unrecognized cron is
*replaced* rather than approximated, commands are tokenized with no shell, `\Microsoft\` is
refused, disable rather than delete — because an assistant without them creates wrong tasks
confidently.

`delete_task` is **off by default** and absent from the tool list entirely unless you set
`CRONSOLE_MCP_ALLOW_DESTRUCTIVE=true`. Leave it off unless you have a reason.

## Keeping it current

This pack is version-stamped. It was generated by your Cronsole install, so it matches the
version you are running today — but a copy on another machine will not update itself. If this
pack and your Cronsole disagree, **Cronsole is right**: re-download the pack from the Tools tab.
