# TaskHub Icon Proposals

Square TaskHub icon proposals for favicons, app icons, and clickable buttons.

Open [`../preview.html`](../preview.html) to compare these icons alongside the landscape logo proposals.

## Dark Icons

- [Command Grid](./dark/favicon-01-command-grid.svg) - connected task rows plus a completion mark.
- [Schedule Orbit](./dark/favicon-02-schedule-orbit.svg) - scheduler clock with automation orbit nodes.
- [Agent Pulse](./dark/favicon-03-agent-pulse.svg) - local agent console relaying to a hub.

## Light Icons

- [Command Grid Light](./light/favicon-01-command-grid-light.svg) - light version of the connected task rows concept.
- [Schedule Orbit Light](./light/favicon-02-schedule-orbit-light.svg) - light version of the scheduler/orbit concept.
- [Agent Pulse Light](./light/favicon-03-agent-pulse-light.svg) - light version of the local agent relay concept.

## Notes

- All links are relative to this README, so they keep working if the entire `logo-proposals/` folder is moved.
- Icon assets use a `256 x 256` viewBox and are safe for square favicon export.
- SVG format keeps the marks crisp for browser favicons, toolbar buttons, app tiles, and README badges.
